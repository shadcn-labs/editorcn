## Installation

**Install via the shadcn registry (recommended):**

```bash
npx shadcn@latest add @editorcn/block-editor
```

This copies the component source directly into your project, so you can customize it freely.

<Callout title="Check your iconLibrary">
  The icons are written for the `iconLibrary` in your `components.json`, which
  must be `lucide`, `tabler`, `hugeicons`, `phosphor` or `remixicon`. Older
  projects with `"iconLibrary": "radix"` get a build error about
  `./icon-placeholder`. Change it to `"lucide"` before installing, and install
  `lucide-react` if your project doesn't have it (the CLI doesn't install icon
  packages). See [Icon library](#icon-library).
</Callout>

**Or install via npm/pnpm:**

```bash
npm install @editorcn/block-editor @tiptap/react @tiptap/pm @tiptap/starter-kit @tiptap/suggestion @tiptap/extension-drag-handle-react
```

After installation, import the editor styles at the root of your application:

```tsx
// Your shadcn globals
import "@/app/globals.css";

// Block editor component styles
import "@/components/block-editor/style.css";
```

> **Order matters**: Import your shadcn globals first, then the editor styles.

If you installed via npm, import from `@editorcn/block-editor` instead of `@/components/block-editor` throughout this page:

```tsx
import {
  BlockEditor,
  SlashCommand,
  defaultSlashCommandItems,
  getSlashCommandSuggestion,
  DEFAULT_ICONS,
} from "@editorcn/block-editor";
import type { BlockEditorIcons } from "@editorcn/block-editor";
import "@editorcn/block-editor/style.css";
```

Then add the package to Tailwind's sources in the CSS file that imports `tailwindcss` (the path is relative to that file). The block editor's chrome is styled with Tailwind classes, and Tailwind doesn't scan `node_modules` by default:

```css
@source "../node_modules/@editorcn/block-editor/dist";
```

## Full setup

To start from the complete block editor on the [homepage](/), install the **Full Block Editor**. It brings the block editor, a slash menu with images, tables, callouts and Markdown import and export, and the [Callout](/docs/extensions/callout), [Code Block](/docs/extensions/code-block), [Image Placeholder](/docs/extensions/image-placeholder), [Markdown](/docs/extensions/markdown), [Mention](/docs/extensions/mention), [Mermaid](/docs/extensions/mermaid), [Paste Cleanup](/docs/extensions/paste-cleanup) and [Table](/docs/extensions/table) extensions in one command:

```bash
npx shadcn@latest add "https://www.rtecn.space/r/full-block-editor.json"
```

It lands in `components/templates/full-block-editor/`:

```tsx
import { FullBlockEditor } from "@/components/templates/full-block-editor";

export const Page = ({ doc }) => (
  <FullBlockEditor
    content={doc.content}
    onChange={(json) => saveDocument(doc.id, json)}
    searchUsers={(query) => fetchUsers(query)}
  />
);
```

| Prop               | Type       | Description                                            |
| ------------------ | ---------- | ------------------------------------------------------ |
| `content`          | `Content`  | Tiptap JSON or HTML to start with                      |
| `onChange`         | `function` | Gets the document as Tiptap JSON                       |
| `searchUsers`      | `function` | Gets the `@` query, returns `MentionItem[]` (async ok) |
| `placeholder`      | `string`   | Placeholder for an empty document                      |
| `markdownFilename` | `string`   | File name for Markdown export, default `document.md`   |
| `className`        | `string`   | Outer container classes                                |

## Install extensions

The usage example below uses the editorcn [Table](/docs/extensions/table) and [Image Placeholder](/docs/extensions/image-placeholder) extensions:

```bash
npx shadcn@latest add @editorcn/table @editorcn/image-placeholder
```

The Tiptap extensions it also uses (placeholder, task lists) come with `@editorcn/block-editor`. With npm, install `@tiptap/extension-placeholder @tiptap/extension-task-list @tiptap/extension-task-item` yourself. The editorcn extensions aren't published to npm, so add them with the command above either way.

## Usage

```tsx
"use client";

import { useEditor } from "@tiptap/react";
import { Suspense } from "react";
import { StarterKit } from "@tiptap/starter-kit";
import { Placeholder } from "@tiptap/extension-placeholder";
import { TaskList } from "@tiptap/extension-task-list";
import { TaskItem } from "@tiptap/extension-task-item";
import {
  BlockEditor,
  SlashCommand,
  getSlashCommandSuggestion,
} from "@/components/block-editor";
import {
  ImagePlaceholder,
  ResizableImage,
  imagePlaceholderSlashCommandItem,
} from "@/components/extensions/image-placeholder";
import { Table, tableSlashCommandItem } from "@/components/extensions/table";
import { TableHoverOverlay } from "@/components/extensions/table/table-hover-overlay";
import "@/components/block-editor/style.css";
import "@/components/extensions/image-placeholder/style.css";
import "@/components/extensions/table/style.css";

function MyBlockEditorInner() {
  const editor = useEditor({
    immediatelyRender: false,
    extensions: [
      StarterKit.configure({
        heading: { levels: [1, 2, 3] },
      }),
      Placeholder.configure({ placeholder: "Type / for commands..." }),
      TaskList,
      TaskItem.configure({ nested: true }),
      Table,
      ResizableImage,
      ImagePlaceholder,
      SlashCommand.configure({
        suggestion: getSlashCommandSuggestion([
          imagePlaceholderSlashCommandItem,
          tableSlashCommandItem,
        ]),
      }),
    ],
  });

  return (
    <div className="relative mx-auto w-full max-w-3xl px-4">
      <BlockEditor editor={editor} />
      <TableHoverOverlay editor={editor} />
    </div>
  );
}

// Tiptap's useEditor reads Math.random(), which Next.js `cacheComponents`
// rejects during prerender. The Suspense boundary keeps the build working.
export function MyBlockEditor() {
  return (
    <Suspense fallback={null}>
      <MyBlockEditorInner />
    </Suspense>
  );
}
```

<Callout title="Next.js with cacheComponents">
  Tiptap's `useEditor` reads `Math.random()`, which Next.js `cacheComponents`
  (on by default in new Next.js 16 apps) rejects during prerender. That's why
  the example renders the editor inside a `<Suspense>` boundary. Keep the
  boundary when you move the editor into your own components.
</Callout>

Each editorcn extension exports a ready-made slash item (`imagePlaceholderSlashCommandItem`, `tableSlashCommandItem`, `calloutSlashCommandItem`, `toggleSlashCommandItem`, and `getMarkdownSlashCommandItems()` for Markdown import and export). Items you pass are merged with the built-in ones, so you only list the extras.

The block editor fills its container, and its drag handles sit in a gutter on the left. Put it in a container with a max width and some side padding, such as `mx-auto w-full max-w-3xl px-4`, so the handles don't land on the edge of the window.

## BlockEditor (Root)

The root wrapper that provides editor context. Renders the full editor UI by default (drag handle, block actions, bubble menu, and content area) or accepts custom children.

### Props

| Prop        | Type                         | Default                       | Description                                                           |
| ----------- | ---------------------------- | ----------------------------- | --------------------------------------------------------------------- |
| `editor`    | `Editor \| null`             | —                             | The Tiptap editor instance                                            |
| `children`  | `ReactNode`                  | —                             | Optional custom children to replace the default layout                |
| `className` | `string`                     | —                             | Additional CSS classes                                                |
| `preset`    | `"block" \| "document"`      | `"block"`                     | [Content preset](/docs/styling#content-presets)                       |
| `labels`    | `Partial<BlockEditorLabels>` | `DEFAULT_BLOCK_EDITOR_LABELS` | Override default slash command labels                                 |
| `icons`     | `Partial<BlockEditorIcons>`  | `DEFAULT_ICONS`               | Override any built-in icon (slash commands, bubble menu, drag handle) |

### Icons

The default icons come from the `iconLibrary` in your `components.json` (see [Icon library](#icon-library)) and inherit your theme's colors (they render with `currentColor`). The npm package uses `lucide-react`.

### Labels

| Key                | Default           | Description              |
| ------------------ | ----------------- | ------------------------ |
| `paragraphLabel`   | `"Text"`          | Label for paragraph node |
| `headingLabel`     | `"Heading"`       | Label for heading nodes  |
| `bulletListLabel`  | `"Bullet list"`   | Label for bullet list    |
| `orderedListLabel` | `"Numbered list"` | Label for ordered list   |
| `taskListLabel`    | `"To-do list"`    | Label for task list      |
| `blockquoteLabel`  | `"Quote"`         | Label for blockquote     |
| `codeBlockLabel`   | `"Code"`          | Label for code block     |
| `dividerLabel`     | `"Divider"`       | Label for divider        |

## BlockEditor.Content

Renders the editor content area with the drag handle and block actions, plus the [bottom bar](#blockeditorbottombar) on touch devices. Use this when providing custom children to the root.

```tsx
<BlockEditor editor={editor}>
  <BlockEditor.Content />
</BlockEditor>
```

## BlockEditor.BubbleMenu

A standalone bubble menu component that can be used outside the BlockEditor root. Useful if you want to customize the bubble menu position or behavior.

```tsx
<BlockEditor editor={editor}>
  <BlockEditor.Content />
  <BlockEditor.BubbleMenu />
</BlockEditor>
```

## BlockEditor.BottomBar

A formatting bar that is pinned to the bottom of the editor and shown only on touch devices (`(hover: none) and (pointer: coarse)`). `BlockEditor.Content` already renders it, so you only need it when composing your own layout.

```tsx
<BlockEditor editor={editor}>
  <EditorContent editor={editor} />
  <BlockEditor.BottomBar editor={editor} />
</BlockEditor>
```

| Prop     | Type     | Default | Description          |
| -------- | -------- | ------- | -------------------- |
| `editor` | `Editor` | —       | The Tiptap instance. |

It contains:

- **Add block** — Opens the slash command menu. If the current block has text, a new paragraph is inserted below it first.
- **Node type selector**, **inline formatting**, **text color**, **link**, and **text alignment** (when `@tiptap/extension-text-align` is registered) — The same controls as the bubble menu.

The bar scrolls horizontally with edge fades when the controls overflow, opens its dropdowns upward, and stays above the on-screen keyboard using the `visualViewport` API.

## Features

### Slash command menu

Type `/` to open the slash command menu. The menu shows available block types. Navigate with arrow keys and press Enter to insert.

**Available commands:**

| Command       | Description                                                                           |
| ------------- | ------------------------------------------------------------------------------------- |
| Text          | Plain paragraph                                                                       |
| Heading 1/2/3 | Section headings                                                                      |
| Bullet List   | Unordered list                                                                        |
| Numbered List | Ordered list                                                                          |
| Task List     | Checklist with checkboxes                                                             |
| Quote         | Blockquote                                                                            |
| Code          | Code block (highlighted with the [Code Block extension](/docs/extensions/code-block)) |
| Divider       | Horizontal rule                                                                       |

### Custom slash command items

```tsx
import { getSlashCommandSuggestion } from "@/components/block-editor";
import type { SlashCommandSuggestionItem } from "@/components/block-editor";

const myItems: SlashCommandSuggestionItem[] = [
  {
    id: "custom",
    title: "Custom",
    description: "A custom command",
    keywords: ["custom"],
    command: ({ editor, range }) => {
      editor.chain().focus().deleteRange(range).insertContent("Hello!").run();
    },
  },
];
```

Pass the array to `getSlashCommandSuggestion(myItems)`. Your items are shown first, followed by the built-in ones, so you don't need to spread `defaultSlashCommandItems`. An item with the same `id` as a built-in one replaces it.

### Custom icons

The default icons follow your `iconLibrary` (see [Icon library](#icon-library)). Override any built-in icon via the `icons` prop. All icons accept a `ReactNode`, so you can use inline SVGs, emoji, or any icon library.

```tsx
import { BlockEditor, DEFAULT_ICONS } from "@/components/block-editor";
import type { BlockEditorIcons } from "@/components/block-editor";

<BlockEditor
  editor={editor}
  icons={{
    slashTextIcon: <span>T</span>,
    slashHeadingIcon: <span>H</span>,
    boldIcon: <strong>B</strong>,
    dragHandleIcon: <span>:::</span>,
  }}
/>;
```

Each slash command item also accepts an `icon` property. Override individual items to change their icon without replacing all defaults:

```tsx
import { getSlashCommandSuggestion } from "@/components/block-editor";
import { imagePlaceholderSlashCommandItem } from "@/components/extensions/image-placeholder";

const suggestion = getSlashCommandSuggestion([
  { ...imagePlaceholderSlashCommandItem, icon: <MyImageIcon /> },
]);
```

### Icon library

The icons follow the `iconLibrary` in your `components.json`. `block-editor/icons.tsx` is written with shadcn's `IconPlaceholder`, and when you add the block editor, the shadcn CLI swaps each placeholder for the matching icon from Lucide, Tabler, HugeIcons, Phosphor or Remix Icon. This needs shadcn CLI 4.7.0 or newer, which `npx shadcn@latest` always is.

`iconLibrary` has to be one of the five libraries above. Older projects may still have `"iconLibrary": "radix"`, which the CLI skips, so the placeholders stay in the file and the build fails on the `./icon-placeholder` import. Set it to `"lucide"` (or another supported library) before adding the block editor.

The CLI doesn't install the icon package. `shadcn init` installs it for your `iconLibrary`, so it's usually there already. If not, add it:

| `iconLibrary` | Package                                             |
| ------------- | --------------------------------------------------- |
| `lucide`      | `lucide-react`                                      |
| `tabler`      | `@tabler/icons-react`                               |
| `hugeicons`   | `@hugeicons/react` and `@hugeicons/core-free-icons` |
| `phosphor`    | `@phosphor-icons/react`                             |
| `remixicon`   | `@remixicon/react`                                  |

This covers every slash menu, bubble menu and drag handle icon, plus the add-block buttons. `icons.tsx` is yours after install, so you can still edit it or override single keys with the `icons` prop.

Changed `iconLibrary` after installing? Re-add the block editor (this overwrites your edits to its files), or migrate the installed files:

```bash
npx shadcn@latest migrate icons --from lucide --to phosphor "src/components/block-editor/**"
```

The `block-editor-icons-*` items from earlier releases are gone, because the block editor itself now installs the right icons.

> **npm/pnpm installs**: the npm package uses `lucide-react`. To use another library, pass your own icons through the `icons` prop.

### Language icons

The code block language selector shows the language name (properly capitalized, e.g. **TypeScript**, **C++**, **JSON**) alongside its icon. Override per-language icons via the `languageIcons` key:

```tsx
import {
  BlockEditor,
  DEFAULT_ICONS,
  DEFAULT_LANGUAGE_ICONS,
} from "@/components/block-editor";

<BlockEditor
  editor={editor}
  icons={{
    ...DEFAULT_ICONS,
    languageIcons: {
      ...DEFAULT_LANGUAGE_ICONS,
      jsx: <YourJsxIcon />,
    },
  }}
/>;
```

Exported constants:

| Export                   | Description                                                                     |
| ------------------------ | ------------------------------------------------------------------------------- |
| `DEFAULT_ICONS`          | Default toolbar, slash menu, and bubble menu icons                              |
| `DEFAULT_LANGUAGE_ICONS` | Per-language icons for 21 languages (js, ts, python, rust, go, html, css, etc.) |

**Available icon keys:**

### Slash items from editorcn extensions

Each editorcn extension exports a slash item, so you don't have to write the command yourself. Register the extension and pass its item:

| Item                               | Extension                                                 |
| ---------------------------------- | --------------------------------------------------------- |
| `imagePlaceholderSlashCommandItem` | [Image Placeholder](/docs/extensions/image-placeholder)   |
| `tableSlashCommandItem`            | [Table](/docs/extensions/table)                           |
| `calloutSlashCommandItem`          | [Callout](/docs/extensions/callout)                       |
| `toggleSlashCommandItem`           | [Toggle](/docs/extensions/toggle)                         |
| `getMarkdownSlashCommandItems()`   | [Markdown](/docs/extensions/markdown) (import and export) |

```tsx
import {
  calloutSlashCommandItem,
  Callout,
} from "@/components/extensions/callout";
import {
  ImagePlaceholder,
  ResizableImage,
  imagePlaceholderSlashCommandItem,
} from "@/components/extensions/image-placeholder";
import {
  Markdown,
  getMarkdownSlashCommandItems,
} from "@/components/extensions/markdown";
import { Table, tableSlashCommandItem } from "@/components/extensions/table";
import { Toggle, toggleSlashCommandItem } from "@/components/extensions/toggle";

const editor = useEditor({
  extensions: [
    StarterKit,
    Table,
    ResizableImage,
    ImagePlaceholder,
    Callout,
    Toggle,
    Markdown,
    SlashCommand.configure({
      suggestion: getSlashCommandSuggestion([
        imagePlaceholderSlashCommandItem,
        tableSlashCommandItem,
        calloutSlashCommandItem,
        toggleSlashCommandItem,
        ...getMarkdownSlashCommandItems("notes.md"),
      ]),
    }),
  ],
});
```

Install the extensions with `npx shadcn@latest add @editorcn/image-placeholder @editorcn/table @editorcn/callout @editorcn/toggle @editorcn/markdown`, and import each extension's `style.css` as its page describes.

### Bubble menu

Select text to see the floating bubble menu with:

- **Node type selector** — Switch between paragraph, headings, lists, etc. (with icons)
- **Inline formatting** — Bold, Italic, Underline, Strike, Code (with icons)
- **Text color** — A single color button opens a dropdown with two stacked grids: **Text color** (when `@tiptap/extension-text-style` + `@tiptap/extension-color` are registered) and **Highlight** (when `@tiptap/extension-highlight` is registered with `multicolor: true`), each with a remove action
- **Link insertion/removal** — Add or remove links
- **Text alignment** — Left, Center, Right (with icons)

The bubble menu automatically positions itself near the selection and is styled with your theme's `--popover` tokens. All bubble menu icons can be overridden via the `icons` prop.

### Text color & highlight

The bubble menu's color button opens a dropdown with two stacked grids — **Text color** and **Highlight** — each with an 8-color palette and a remove action. Colors you pick are remembered in `localStorage` and shown in a **Recently Used** row (up to 10).

Sections only render when the matching extensions are registered:

| Section    | Required extensions                                        |
| ---------- | ---------------------------------------------------------- |
| Text color | `@tiptap/extension-text-style` + `@tiptap/extension-color` |
| Highlight  | `@tiptap/extension-highlight` (with `multicolor: true`)    |

```bash
npm install @tiptap/extension-text-style @tiptap/extension-color @tiptap/extension-highlight
```

```tsx
import { TextStyle } from "@tiptap/extension-text-style";
import { Color } from "@tiptap/extension-color";
import { Highlight } from "@tiptap/extension-highlight";

const editor = useEditor({
  extensions: [
    StarterKit,
    TextStyle,
    Color,
    Highlight.configure({ multicolor: true }),
  ],
});
```

### Block actions

Click the drag handle (grip icon) on the left side of any block to access a dropdown with:

- **Copy** — Copy the current block content to clipboard (shows a checkmark animation on success)
- **Delete** — Delete the current block

### Drag handle

Drag blocks to reorder them using the grip icon on the left. The drag handle uses `@tiptap/extension-drag-handle-react`.

### Touch devices

On touch devices the drag handle, add-block button, and bubble menu are hidden, and the content's left gutter is removed. Formatting and block insertion move to the [bottom bar](#blockeditorbottombar).

## Extensions

All `@tiptap/*` packages are **peer dependencies**, so there is only one copy of Tiptap in your project and its types don't clash. The shadcn registry install adds them for you; with npm/pnpm, install them yourself.

| Extension                             | Purpose                             | Required |
| ------------------------------------- | ----------------------------------- | -------- |
| `@tiptap/starter-kit`                 | Core editor functionality           | Yes      |
| `@tiptap/pm`                          | ProseMirror runtime                 | Yes      |
| `@tiptap/react`                       | React bindings                      | Yes      |
| `@tiptap/suggestion`                  | Slash command suggestion engine     | Yes      |
| `@tiptap/extension-drag-handle-react` | Block drag handle UI                | Yes      |
| `@tiptap/extension-placeholder`       | Placeholder text                    | Optional |
| `@tiptap/extension-text-style`        | Text color - together with `Color`  | Optional |
| `@tiptap/extension-color`             | Text color (requires Text Style)    | Optional |
| `@tiptap/extension-highlight`         | Highlight (with `multicolor: true`) | Optional |

`StarterKit` v3 already includes Link and Underline. For images, tables, callouts, toggles, code highlighting, mentions and Markdown, use the [editorcn extensions](/docs/extensions). Each one that inserts a block exports a slash item; see [Slash items from editorcn extensions](#slash-items-from-editorcn-extensions).

## Syntax highlighting

`StarterKit` includes a plain code block. For syntax highlighting, a language menu, copy, wrap, captions, formatting and Mermaid diagrams, install the [Code Block extension](/docs/extensions/code-block) and turn off the built-in one:

```tsx
import { CodeBlock } from "@/components/extensions/code-block";

const editor = useEditor({
  extensions: [
    StarterKit.configure({ codeBlock: false }),
    CodeBlock,
    SlashCommand.configure({
      suggestion: getSlashCommandSuggestion(),
    }),
  ],
});
```

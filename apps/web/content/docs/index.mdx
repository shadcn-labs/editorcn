Rich text editor components built on [Tiptap](https://tiptap.dev/) for the [shadcn/ui](https://ui.shadcn.com/) ecosystem.

## Packages

editorcn provides two editors, a set of extensions that work with both, and a read-only renderer:

### [@editorcn/editor](/docs/editor)

A **toolbar-style** rich text editor with a compound component API. Perfect for traditional editing experiences with a top toolbar.

- `RichTextEditor` — root component with toolbar and content area
- `RichTextEditor.Toolbar` — sticky toolbar with control groups
- 20+ built-in toolbar controls (Bold, H1, Link, Undo, etc.)

[View docs →](/docs/editor)

### [@editorcn/block-editor](/docs/block-editor)

A **Notion-style** block-type rich text editor. Ideal for modern, block-based writing experiences.

- `BlockEditor` — block-type editor with slash commands and drag handles
- Slash command menu (type `/` to insert blocks)
- Bubble menu for inline formatting
- Drag handles to reorder blocks, with copy and delete actions
- Images, tables, callouts and toggles through the [extensions](/docs/extensions), each with a ready-made slash item

[View docs →](/docs/block-editor)

### [Extensions](/docs/extensions)

Ready-made Tiptap extensions for both editors: Callout, Code Block, Image Placeholder, Markdown, Mention, Paste Cleanup, Table and Toggle. Each installs on its own with the shadcn CLI and brings its toolbar control or slash item.

### [Static Renderer](/docs/static-renderer)

Renders saved editor content as read-only HTML, for blog posts, previews and chat history, without loading an editor.

### [Templates](/docs/templates)

Complete editors you install in one command, such as the full toolbar and block editors from the homepage, a comment box and an email composer.

## Which one should I use?

| You want...                                            | Use                      |
| ------------------------------------------------------ | ------------------------ |
| A traditional toolbar editor (WordPress, Medium-style) | `@editorcn/editor`       |
| A block-based editor (Notion, Linear-style)            | `@editorcn/block-editor` |
| Both in the same app                                   | Install both packages    |

## Common Features

Both editors share:

- Built with shadcn/ui design tokens and CSS variables
- Full TypeScript support
- Extensible via Tiptap extensions
- Lightweight and modular

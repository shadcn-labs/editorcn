---
title: Image
description: Insert an image by URL from a dialog.
---

The Image control opens a dialog when the button is clicked, with an input field to enter an image URL, and inserts the image at the cursor position.

<ControlInstall slug="image" />

The control requires the image extension:

```bash
npm install @tiptap/extension-image
```

## Use with `@editorcn/editor`

Use the image control in the toolbar below and paste an image URL.

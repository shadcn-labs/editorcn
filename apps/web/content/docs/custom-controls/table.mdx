---
title: Table
description: Insert and manage tables from the editor toolbar.
---

The Table control inserts a 3×3 table with a header row, then manages it while the cursor is inside a table: add or delete rows and columns, merge and split cells, and toggle the header row. A "Delete table" action is always available.

<ControlInstall slug="table" />

The control requires the table extensions:

```bash
npm install @tiptap/extension-table @tiptap/extension-table-row @tiptap/extension-table-cell @tiptap/extension-table-header
```

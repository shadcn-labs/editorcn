title: Highlight Color
description: Apply a highlight mark color from a popover palette.
---

The Highlight Color control opens a popover with a color swatch grid. It applies the selected color as a highlight mark and offers a button to remove existing highlights.

<ControlInstall slug="highlight-color" />

The control requires the highlight extension with multicolor enabled:

```bash
npm install @tiptap/extension-highlight
```

## Use with `@editorcn/editor`

Select some text below, then pick a color from the highlight popover in the toolbar.

---
title: Insert Link
description: Insert a hyperlink from a URL dialog.
---

The Insert Link control opens a dialog when the button is clicked, with an input field to enter a URL. The link text of the current selection is detected and prefilled.

<ControlInstall slug="insert-link" />

The control requires the link extension:

```bash
npm install @tiptap/extension-link
```

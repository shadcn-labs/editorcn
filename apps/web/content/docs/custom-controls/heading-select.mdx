---

The Heading Select is a unified dropdown that toggles between paragraph and heading levels (H1–H3). It stays in sync with the cursor position as you move through your document.

<ControlInstall slug="heading-select" />

No additional extensions are required — paragraph and heading nodes ship with Starter Kit.

## Use with `@editorcn/editor`

Place the cursor in the heading or paragraph below, then open the select in the toolbar.

Pre-built custom toolbar controls for the rich text editor. Each control lives on its own page with a live preview and a usage snippet.

Every control is installed individually with `shadcn`:

```bash
npx shadcn@latest add "https://editorcn.vercel.app/r/custom-controls-table"
```

Each page documents what the control does, the editor extensions it requires, a live preview, and how to wire it into your toolbar.

## September 16, 2026 - Editor UX polish

Reworked the editor surfaces: table handles now use three-dot menus, the rich text editor gained reusable UI primitives, and both editors' bubble menus now share a single color control with stacked text color and highlight grids. See the [full entry](/docs/changelog/2026-09-16-extension-ux-polish).

## September 11, 2026 - Static renderer JSON support

`@editorcn/static-renderer` now renders saved Tiptap JSON documents and can map custom nodes (like images) to your own React components. The live docs demo also lets you change the preview image by URL or file. See the [full entry](/docs/changelog/2026-09-11-static-renderer-json-support).

## August 30, 2026 - Static renderer

A new `@editorcn/static-renderer` package renders content from either editor as read-only, fully styled HTML. Install via the shadcn registry or npm. See the [full entry](/docs/changelog/2026-08-30-static-renderer).

## August 27, 2026 - Tiptap v3

All editor and block editor packages now run on **Tiptap v3**, with the bubble menu migrated to Floating UI and table extensions consolidated into `TableKit`. See the [full entry](/docs/changelog/2026-08-27-tiptap-v3).

## August 27, 2026 - Lucide icons & language labels

The Block Editor now uses **lucide-react** icons (instead of custom SVGs) and shows capitalized language names in the code block selector. See the [full entry](/docs/changelog/2026-08-27-lucide-icons-and-language-labels).

## August 26, 2026 - Initial Release

We shipped the initial release of editorcn with beautifully designed, accessible, and customizable rich text editor components built on Tiptap.

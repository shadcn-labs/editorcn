Pasting from Google Docs, Notion, Word, or a web page now comes out clean with the new [Paste Cleanup extension](/docs/extensions/paste-cleanup).

```bash
npx shadcn@latest add "https://editorcn.vercel.app/r/paste-cleanup.json"
```

## Highlights

- **Theme-friendly pastes**: classes, ids, fonts, sizes, colors, and margins are stripped, so pasted text matches your editor.
- **Formatting kept**: bold, italic, underline, strikethrough, subscript, superscript, and links come through, including Google Docs formatting written as `font-weight` and `font-style` spans.
- **Word lists**: Word's indented `mso-list` paragraphs become real nested bullet and numbered lists.
- **No empty lines**: empty paragraphs and the blank lines Google Docs adds between blocks are removed.
- **Editor-to-editor paste untouched**: copying between editorcn editors keeps mentions, task lists, and custom nodes exactly as they were.
- **Configurable**: turn off `stripStyles`, `convertWord`, or `removeEmptyParagraphs` with `PasteCleanup.configure()`.

The landing page editors and the Simple Document Editor template now include it.

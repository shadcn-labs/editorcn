Editorcn ships a set of ready-to-use [Tiptap extensions](https://tiptap.dev) — real Tiptap `Node`s, `Mark`s and `Extension`s with their own commands — plus a matching toolbar component for each.

Each extension is installed individually with the shadcn CLI and copied into your project as editable source, so you can adjust behavior, options and styles freely. Installing an extension brings its source, its toolbar component and the shared `extensions/core` runtime in one go.

Every extension page has a live preview, an installation guide, usage snippets, the options you can pass to `.configure()`, and the commands the extension adds.

## Available extensions

- [Image Placeholder](/docs/extensions/image-placeholder) — a Notion-style image placeholder node with upload and URL embed support, resizable image node view, and its own toolbar button.
- [Table](/docs/extensions/table) — a table node with a grid-size picker toolbar, row and column management, cell merge and split, hover context handles, and resizable columns.

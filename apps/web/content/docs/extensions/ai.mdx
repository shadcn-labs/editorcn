The AI Assistant extension adds an `AiToolbar` sparkles button to any toolbar editor. Click it, type a free prompt, and the generated text replaces the current selection — or is inserted at the cursor when nothing is selected. The selected text is sent along as context automatically.

<ExtensionPreview slug="ai" editor="toolbar" />

Paste an OpenAI API key above to try it live. The preview posts your prompt to the app's `/api/ai` route below, which calls OpenAI server-side.

> OpenAI's API sends no CORS headers, so browsers block direct calls to it. The toolbar therefore accepts an `endpoint` prop: point it at a same-origin route that forwards to OpenAI (snippet below). Only use keys you are willing to expose client-side — for production apps, keep the key in server env (`OPENAI_API_KEY`) instead of collecting it in the browser.

## Installation

Run the following command to install the extension, its toolbar component and the shared extension runtime:

```bash
npx shadcn@latest add "https://editorcn.vercel.app/r/ai.json"
```

This installs `extensions/ai`, `extensions/core/`, `extensions/ui/` and the `ai` + `@ai-sdk/openai` packages. AI styles and shared UI styles are installed as `extensions/ai/style.css` and `extensions/ui/style.css`.

To install the files manually instead, install these packages and copy the code from the [package source](https://github.com/AbdullahMukadam/editorcn/tree/main/packages/extensions/src/ai):

```bash
npm install ai @ai-sdk/openai
```

## Usage

Render `AiToolbar` inside a `ToolbarProvider` and pass your user's OpenAI key. No tiptap extension registration is needed — the toolbar works with any editor.

```tsx
"use client";

import { useState } from "react";
import { useEditor } from "@tiptap/react";
import StarterKit from "@tiptap/starter-kit";

import { RichTextEditor } from "@/components/editor";
import { ToolbarProvider } from "@/components/extensions/core";
import { AiToolbar } from "@/components/extensions/ai/toolbar";

import "@/components/editor/style.css";
import "@/components/extensions/ai/style.css";
import "@/components/extensions/ui/style.css";

export function MyEditor({ apiKey }: { apiKey: string }) {
  const editor = useEditor({
    immediatelyRender: false,
    extensions: [StarterKit],
  });

  return (
    <RichTextEditor editor={editor}>
      <RichTextEditor.Toolbar>
        <RichTextEditor.ControlsGroup>
          <RichTextEditor.Bold />
          <RichTextEditor.Italic />
        </RichTextEditor.ControlsGroup>
        <RichTextEditor.ControlsGroup>
          <ToolbarProvider editor={editor}>
            <AiToolbar apiKey={apiKey} />
          </ToolbarProvider>
        </RichTextEditor.ControlsGroup>
      </RichTextEditor.Toolbar>
      <RichTextEditor.Content />
    </RichTextEditor>
  );
}
```

## Settings

### `apiKey`

Your OpenAI API key (BYOK). The button is disabled until a key is provided.

```tsx
<AiToolbar apiKey={apiKey} />
```

### `model`

OpenAI model id. Defaults to `gpt-4o-mini`.

```tsx
<AiToolbar apiKey={apiKey} model="gpt-4o" />
```

### `endpoint`

Proxy endpoint for the OpenAI request. **Required with OpenAI** — browsers block direct calls to `api.openai.com` (no CORS headers). Same-origin paths work as-is:

```tsx
<AiToolbar apiKey={apiKey} endpoint="/api/ai" />
```

Example route (`app/api/ai/route.ts`), using the same `ai` + `@ai-sdk/openai` packages. It accepts an `apiKey` from the client or falls back to `OPENAI_API_KEY` env:

```tsx
import { createOpenAI } from "@ai-sdk/openai";
import { generateText } from "ai";
import { NextResponse } from "next/server";

export const POST = async (request: Request) => {
  const { apiKey, model = "gpt-4o-mini", prompt, context } =
    await request.json();
  const key = apiKey?.trim() || process.env.OPENAI_API_KEY;
  if (!key) return NextResponse.json({ error: "Missing API key." }, { status: 400 });

  const openai = createOpenAI({ apiKey: key });
  const { text } = await generateText({
    model: openai(model),
    prompt: context ? `Text:\n${context}\n\nInstruction:\n${prompt}` : prompt,
    system: "You are a writing assistant. Respond with plain text only.",
  });
  return NextResponse.json({ text: text.trim() });
};
```

### `labels`

Override the button tooltip, prompt placeholder, submit label, and missing-key hint.

```tsx
<AiToolbar
  apiKey={apiKey}
  labels={{ placeholder: "Rewrite this…", submit: "Go" }}
/>
```

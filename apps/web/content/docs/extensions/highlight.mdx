The Highlight extension configures Tiptap's highlight mark with multicolor support and ships a `HighlightToolbar` popover with a small color palette. Select text, pick a color from the palette to highlight, and use the "Remove highlight" action to clear it.

## Installation

Run the following command to install the extension, its toolbar component and the shared extension runtime:

```bash
npx shadcn@latest add "https://editorcn.vercel.app/r/highlight.json"
```

To install the files manually instead, install these packages and copy the code from the [package source](https://github.com/AbdullahMukadam/editorcn/tree/main/packages/extensions/src/highlight):

```bash
npm install @tiptap/core @tiptap/extension-highlight
```

## Usage

Register `Highlight` in your editor and add `HighlightToolbar` to a toolbar group. The toolbar accepts an optional `editor` prop or falls back to an `EditorControlsProvider`.

```tsx
"use client";

import { useEditor } from "@tiptap/react";
import StarterKit from "@tiptap/starter-kit";

import { Highlight } from "@/components/extensions/highlight";
import { HighlightToolbar } from "@/components/extensions/highlight-toolbar";
import { RichTextEditor } from "@/components/editor";

import "@/components/editor/style.css";

export function MyEditor() {
  const editor = useEditor({
    immediatelyRender: false,
    extensions: [StarterKit, Highlight],
  });

  return (
    <RichTextEditor editor={editor}>
      <RichTextEditor.Toolbar>
        <RichTextEditor.ControlsGroup>
          <RichTextEditor.Bold />
          <RichTextEditor.Italic />
          <RichTextEditor.Undo />
        </RichTextEditor.ControlsGroup>
        <RichTextEditor.ControlsGroup>
          <HighlightToolbar editor={editor} />
        </RichTextEditor.ControlsGroup>
      </RichTextEditor.Toolbar>
      <RichTextEditor.Content />
    </RichTextEditor>
  );
}
```

## Settings

The `Highlight` extension is a pre-configured `@tiptap/extension-highlight` with `multicolor` enabled. Override any option by calling `.configure` again or editing the source:

```tsx
Highlight.configure({ multicolor: false })
```

### `multicolor`

Enables colored highlighting (as opposed to a single default color). Enabled by default.

```tsx
Highlight.configure({ multicolor: true })
```

### `HTMLAttributes`

HTML attributes applied to the `<mark>` element.

```tsx
Highlight.configure({
  HTMLAttributes: { class: "rounded-sm px-0.5" },
})
```

See the [`@tiptap/extension-highlight`](https://tiptap.dev/docs/editor/extensions/marks/highlight) docs for the full list of options.

## Commands

```tsx
editor.chain().focus().setHighlight({ color: "#fef08a" }).run();

editor.chain().focus().unsetHighlight().run();
```
